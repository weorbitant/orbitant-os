# Lean Startup / MVP / YAGNI

**Origin.** Eric Ries (*The Lean Startup*, 2011) for the MVP; YAGNI ("You Aren't Gonna Need
It") comes from Extreme Programming (Kent Beck, Ron Jeffries).

## Core idea

- **MVP (minimum viable product)**: the smallest version that still solves the problem and
  lets you learn. Not a sloppy version, but the smallest-scope one that delivers the
  essential value.
- **YAGNI**: don't build something because it "might be needed". Scope added "just in case"
  costs today and often never gets used.

Both push you to **cut scope** down to what truly attacks the stated problem, leaving the
rest out (explicitly).

## How it's applied in the guide

- **Rule 8 (YAGNI)**: when the PM adds scope "just in case", it's challenged and, if it
  doesn't solve the stated problem, goes to *Out of scope*.
- **Technique "scope challenge (MVP)"**: "what's the minimal version that still solves the
  problem? What's excess?".
- **Block 10 (out of scope)**: materializes what's decided to be left out.
