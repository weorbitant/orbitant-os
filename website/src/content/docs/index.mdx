## What is orbitant-os?

A plugin marketplace of skills, agents, and commands organized by business vertical. Compatible with Claude Code, Claude.ai, and the Claude API.

<CardGrid stagger>
  <Card title="Skills" icon="pencil">
    Instructions Claude loads automatically when relevant. Claude reads the description and decides when to activate them.
  </Card>
  <Card title="Agents" icon="setting">
    Specialized sub-agents with restricted tools for isolated execution with specific permissions.
  </Card>
  <Card title="Commands" icon="rocket">
    Slash commands invoked manually via `/plugin-name:command-name` for explicit user-triggered actions.
  </Card>
  <Card title="Multi-platform" icon="laptop">
    Works with Claude Code, Claude.ai, Claude API, and 40+ other AI agents via skills.sh.
  </Card>
</CardGrid>

## Quick Install

```bash
# Register the marketplace
/plugin marketplace add weorbitant/orbitant-os

# Install a plugin
/plugin install orbitant-marketing
```
